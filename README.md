# Original Audio Studio

A browser-based procedural game music prototype. It creates new note patterns and synthesized tones with Web Audio; it does not load or sample existing songs.

## Run locally
Open `index.html` in a modern browser such as Chrome. Choose a genre, mood, tempo and duration, then click **Generate original music**. Use **Play** to listen or **Export WAV** to save a mono WAV file.

No build step, server, API key, or paid service is required.

## Current prototype limits
- This is a procedural prototype, not a trained AI music model.
- Sound design and arrangements are intentionally simple and need further development.
- Generated music does not guarantee legal exclusivity or zero similarity risk.
- Planned next steps: better instruments and arrangement, project saving, loop-safe transitions, SFX generation, and game-engine integration.

## Deploy with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
